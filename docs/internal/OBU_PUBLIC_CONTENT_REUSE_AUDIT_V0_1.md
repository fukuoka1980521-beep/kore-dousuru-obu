# 大府市公式コンテンツ 再利用ルール整合監査 v0.1（内部用）

作成日: 2026-08-28
対象: 「これどうする？」大府市版の公開データ（waste_items.json / procedures.json / life_events.json）と、
大府市公式サイトの著作権・利用条件との整合性監査。

このリポジトリの `docs/internal/` は公開repoへ同期しない内部専用領域（`scripts/internal_markers.js` の
`PUBLIC_SURFACE_FILES` に含まれない）。

## 1. 大府市公式サイトの著作権・利用条件の調査結果

調査の結果、大府市公式サイト（city.obu.aichi.jp）には、名古屋市公式サイトにあるような
「コンテンツの再利用に関して（著作権）」の専用ページ（引用条件・二次利用条件を明文化したページ）は
発見できなかった。

確認できたのは以下のみ:

| ページ | URL | 内容 |
|---|---|---|
| 大府市公式ウェブサイトの使い方 | https://www.city.obu.aichi.jp/about/site/howtouse.html | 著作権表記「Copyright © Obu City Office, All Rights Reserved.」のみ確認。転載・引用条件の明文規定は無し |
| 大府市デジタルフォトブック | https://www.city.obu.aichi.jp/shisei/toukei_data/1027811.html | 写真素材についてCreative Commons Attribution 4.0 International相当の記載があるとの検索結果（本文未確認）。品目・手続データの著作権判断には使用していない |

**結論**: 大府市公式サイトの個別案内ページ（ごみ分別・行政手続案内等）について、二次利用可能なオープン
データとしての明示は確認できなかった。名古屋市版が採用した「①改変なし②半分以内③引用の開始・終了明示
④出典表記」のような公式の引用許諾条件も、大府市では見つけられなかった。したがって、**より保守的な方針**
として、大府市版では公式ページの文章表現を一切そのまま複製せず、事実（品目名・区分・料金・電話番号・
期限等）のみを抽出し、生活者向けに独自の文章で要約する方針を徹底した。

## 2. 公開データ内の「」使用箇所 棚卸し

`municipalities/obu/data/{waste_items,procedures,life_events}.json` の全フィールドを対象に、
「」で囲まれた箇所を機械的に検索した。

```
grep -o "「[^」]\{15,\}」" municipalities/obu/data/*.json
```

**結果: 0件。** 15文字以上の「」引用は残っていない（作成時点で1件検出され、`procedures.json` の
obu-proc-10 `notes` フィールドから逐語引用の「」を除去し独自表現に置き換え済み。詳細は
[[OBU_DIFFERENCE_FINDINGS_V0_1]] を参照）。

短い「」（15文字未満）についても目視確認したが、いずれも固有名詞・制度名の引用
（例: 「引越しワンストップサービス」「おくやみ窓口」「われもの」表示等）であり、公式ページ独自の
文章表現の複製ではない。

## 3. 事実 vs 表現の分離方針

各フィールドは以下の方針で作成した:

- `how_to_dispose` / `how_to` / `conditions` / `conclusion`: 公式ページから抽出した事実（分別区分・
  手順・条件）を、独自の生活者向け文章として再構成。公式ページの文をそのまま流用していない。
- `size_rule` / `fee` / `deadline` / `phone` / `business_hours`: 数値・固有名詞そのものであり、
  他の言い回しがほぼ存在しない「事実」として、名古屋市版の監査（[[OBU_DIFFERENCE_FINDINGS_V0_1]]
  参照元の分類A相当）と同じ扱いとした。
- `official_page_title`: 公式ページのタイトルそのもの（識別のための固有名詞的表記であり、著作物性の
  ある「表現」の引用ではない）。
- `notes`: 不明点・出典補足を独自にまとめたもの。公式ページ文の転記ではない。

## 4. UNCONFIRMED/PARTIAL品目の著作権上の位置づけ

`蛍光灯・蛍光管` `LED照明器具` 等、公式情報で確認できなかった品目は、著作権の問題ではなく
**情報の存在自体を確認できなかった**ケースである。これらは事実を断定せず
`"公式情報で確認できませんでした。"` と明記し、著作権リスクではなく正確性リスクとして
`docs/internal/OBU_DIFFERENCE_FINDINGS_V0_1.md` および `docs/obu/OBU_OFFICIAL_SOURCE_REGISTER.md`
に記録した。

## 5. 結論

- 大府市版の公開データに、公式ページからの逐語的な文章複製は残っていない（0件）。
- 大府市公式サイトに二次利用許諾の明文規定が見つからなかったため、名古屋市版よりも保守的に
  「事実抽出＋独自表現」を徹底した。
- 引用が必要と判断した箇所（今回は無し）が将来発生した場合は、大府市への出典確認・許諾確認を
  個別に行うこと。
